# Responsive Grid Layout

A simple, responsive grid layout built using **HTML** and **CSS**. This project is meant to serve as a structural demo to understand how layouts adapt across screen sizes using CSS Grid and media queries.

## 📐 Features

- 📱 Fully responsive design
- 🔲 CSS Grid-based layout structure
- 🎯 Scalable and adaptable for real-world projects
- 💡 No JavaScript used – only HTML & CSS

## 💻 Technologies Used

- HTML5
- CSS3 (including Media Queries & CSS Grid)
